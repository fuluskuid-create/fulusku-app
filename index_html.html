Panduan Instal Android

  1. Buka web Fulusku ini menggunakan browser Google Chrome di HP Anda.
  2. Ketuk ikon menu tiga titik (⋮) di pojok kanan atas browser.
  3. Cari dan pilih opsi "Tambahkan ke Layar Utama" (Add to Home screen).
  4. Ketuk tombol "Tambahkan" pada jendela konfirmasi.
  5. Selesai! Ikon aplikasi Fulusku akan muncul di Home Screen.
